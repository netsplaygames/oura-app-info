# OuraDataAnalysis

A private Python application for accessing and analyzing my own Oura data.
This application is for my personal use and is not offered to other users.

## Privacy Policy

The application currently retrieves my personal information from Oura
with my explicit authorization and displays it locally on my Windows PC.

OAuth credentials and tokens are stored locally in a .env file,
which is excluded from version control.
Health data and credentials are not published in this repository.

Google Sheets storage and AI-assisted analysis are planned but are not
currently implemented. This policy will be updated before enabling them
to describe the data shared with those services.

I can revoke the application's access through Oura and delete local data
and credentials at any time.
